# Generative AI Usage and Academic Outcomes

## Project Overview

This project explores the relationship between Generative AI (GenAI) usage and student academic outcomes through three interactive dashboards developed using **Tableau**.

The dashboards examine student academic performance, GenAI usage patterns, demographics, institutional AI policies, and potential burnout risks to provide insights into how students use generative AI in academic settings.

## Project Objectives

- Explore relationships between GenAI usage and academic performance.
- Analyze GPA trends across different student groups and GenAI use cases.
- Examine student demographics, subscription patterns, and institutional AI policies.
- Investigate the relationship between GenAI usage and student burnout risk.

## Dashboard 1: GenAI Usage and Academic Outcomes

Explores student academic performance and its relationship with GenAI usage.

**Key visualizations:**
- GPA analysis across student groups
- Weekly GenAI usage and GPA changes
- Academic outcomes by prompt-engineering skills
- Burnout risk distribution
